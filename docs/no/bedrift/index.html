Daglig PDF-arbeid for hele teamet, uten lisenser og opplasting

Mange bedrifter betaler for PDF-programmer som de ansatte mest bruker til å signere, slå sammen og rette litt tekst. LunaVerta gjør det gratis i nettleseren, på hver persons egen datamaskin, så ingen kundedata lastes opp.

Prøv LunaVerta nå

Hva koster PDF-lisensene deres?

2 880 € per år → LunaVerta: 0 €

Eksempel: Adobe Acrobat Pro for team koster 180 DKK (ca. 24 €) per bruker per måned eks. mva. med årsavtale (Adobes danske listepris, november 2026). Skriv inn deres egen pris.

Dette klarer LunaVerta

  • Rett eksisterende tekst i en PDF, legg til tekst, fyll ut og lag skjemaer
  • Signer avtaler med en tegnet eller opplastet signatur
  • Slå sammen, del, omorganiser, roter, beskjær og komprimer PDF-er
  • Fjern fødselsnumre, priser og andre personopplysninger for godt
  • OCR på sju språk, sammenlign to versjoner, passordbeskyttelse
  • Word, Excel og PowerPoint til PDF; PDF til Word, Excel og bilder

Dette erstatter det ikke

  • Kvalifiserte elektroniske signaturer med sertifikat (f.eks. BankID-signering)
  • PDF/A for langtidsarkivering
  • Trykklar PDF for profesjonelt trykk (fargeprofiler, utfallende)

Trenger dere det, behold en lisens for de få som gjør det. Alle andre kan bruke LunaVerta.

Bra for GDPR og sikkerhet

  • Filene behandles i nettleseren og lastes aldri opp. Det finnes ingen server som tar imot dem.
  • Ingen kontoer, så det er ingen brukere å administrere og ingen passord som kan lekke.
  • En streng Content Security Policy hindrer siden i å sende data til andre adresser.
  • Åpen kildekode (AGPL-3.0): IT-avdelingen kan lese koden på GitHub.
  • Fungerer uten nett etter første besøk.

Det tar et minutt å komme i gang

Send lenken til teamet, eller installer LunaVerta som app fra Chrome eller Edge (installer-ikonet i adressefeltet). Ingenting å installere sentralt, ingen lisensnøkler og ingen oppdateringer å rulle ut. Fungerer i Chrome, Edge, Safari og Firefox, på datamaskin og telefon.

Trenger dere en egen versjon?

Midt-Tech, selskapet bak LunaVerta, kan kjøre den på deres eget nettverk, legge til logoen deres eller bygge de PDF-arbeidsflytene bedriften trenger.

Spørsmål om LunaVerta

Er det virkelig gratis for bedrifter?

Ja. Det er gratis å bruke LunaVerta i bedriften. Koden er AGPL-3.0, som bare krever at dere deler endringene hvis dere kjører en endret versjon som offentlig nettsted.

Kan vi drifte den selv?

Ja. LunaVerta er en mappe med statiske filer, så enhver webserver eller intranett kan kjøre den. Koden og veiledningen ligger på GitHub.

Hvem står bak LunaVerta?
