Send en lønnsslipp trygt

Utleiere, banker og nye arbeidsgivere ber ofte om å se en lønnsslipp. De trenger inntekten din, ikke fødselsnummeret eller bankkontoen din. Slik sender du bare det de trenger.

Steg for steg

  1. Åpne Sladd PDF, og velg lønnsslippen.
  2. Fødselsnummer, kontonumre, e-post og telefonnummer blir funnet og markert med gult.
  3. Behold det mottakeren skal se. Er lønnsbeløpene markert, slår du av kategorien Priser, så de blir stående.
  4. Klikk på Fjern … og lagre ny versjon, og send den lagrede kopien.

Hva som skal bort, og hva som skal bli

  • Fjern: fødselsnummer, kontonummer, skatteopplysninger du ikke er bedt om, og adressen din hvis mottakeren allerede har den.
  • Behold: navnet ditt, arbeidsgiveren, perioden og lønnsbeløpene. Det er som regel det mottakeren skal sjekke.

Flere måneder?

Blir du bedt om tre måneder, sladder du hver lønnsslipp og slår dem sammen etterpå med Slå sammen PDF, så du bare sender én fil.
