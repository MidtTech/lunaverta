Steuer-ID und Sozialversicherungsnummer aus einem PDF entfernen

Kennnummern wie die Steuer-ID oder die Sozialversicherungsnummer auf einem Dokument, das du weitergibst, können missbraucht werden. So entfernst du sie richtig, sodass sie wirklich aus der Datei verschwinden und nicht nur verdeckt sind.

Schritt für Schritt

  1. Öffne PDF schwärzen und wähle dein PDF.
  2. LunaVerta geht jede Seite durch und markiert Kennnummern gelb, dazu weitere Angaben, die man meist entfernt, zum Beispiel IBANs, E-Mail-Adressen und Telefonnummern.
  3. Willst du nur die Kennnummer entfernen, schalte die anderen Kategorien aus. Tippe auf eine Markierung, um genau diesen Text zu behalten.
  4. Klicke auf … entfernen und neue Version speichern. Der markierte Text wird aus der Datei gelöscht, und eine Kopie wird auf deinem Gerät gespeichert. Das Original bleibt unverändert.

Warum ein schwarzer Kasten in Word oder im PDF-Reader nicht reicht

Ein schwarzes Rechteck über einer Nummer verdeckt sie meist nur. Der Text liegt weiter darunter, und jeder kann ihn herauskopieren oder mit einer Suche finden. LunaVerta löscht die Zeichen selbst, sodass nichts zum Kopieren übrig bleibt.

Das Ergebnis prüfen

Öffne das gespeicherte PDF, drücke Strg+F (oder Cmd+F auf dem Mac) und suche nach den ersten Ziffern der Nummer. Es darf nichts gefunden werden.

Gescannte Dokumente

Ist das PDF ein Scan (ein Bild von Papier), gibt es keinen Text zum Durchsuchen. Nutze Schwärzen im selben Fenster und zieh selbst einen Kasten über die Nummer; er wird beim Speichern fest ins Bild eingebrannt.
