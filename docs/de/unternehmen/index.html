Alltägliche PDF-Arbeit für das ganze Team, ohne Lizenzen und Upload

Viele Unternehmen zahlen für PDF-Software, die die meisten nur zum Unterschreiben, Zusammenfügen und für kleine Textkorrekturen nutzen. LunaVerta macht das kostenlos im Browser, auf dem eigenen Rechner jeder Person, sodass keine Kundendaten hochgeladen werden.

LunaVerta jetzt ausprobieren

Was kosten eure PDF-Lizenzen?

2.880 € pro Jahr → LunaVerta: 0 €

Beispiel: Adobe Acrobat Pro für Teams kostet 180 DKK (etwa 24 €) pro Nutzer und Monat zzgl. MwSt. im Jahresvertrag (Adobes dänischer Listenpreis, November 2026). Gib euren eigenen Preis ein.

Das kann LunaVerta

  • Vorhandenen Text im PDF ändern, Text hinzufügen, Formulare ausfüllen und erstellen
  • Verträge mit gezeichneter oder hochgeladener Unterschrift unterschreiben
  • PDFs zusammenfügen, teilen, ordnen, drehen, zuschneiden und komprimieren
  • Steuer-ID, Preise und andere personenbezogene Daten dauerhaft entfernen
  • OCR in sieben Sprachen, zwei Versionen vergleichen, Passwortschutz
  • Word, Excel und PowerPoint in PDF; PDF in Word, Excel und Bilder

Das ersetzt es nicht

  • Qualifizierte elektronische Signaturen mit Zertifikat
  • PDF/A für die Langzeitarchivierung
  • Druckfertige PDFs für den professionellen Druck (Farbprofile, Beschnitt)

Wenn ihr das braucht, behaltet eine Lizenz für die wenigen, die es nutzen. Alle anderen können LunaVerta verwenden.

Gut für DSGVO und Sicherheit

  • Dateien werden im Browser verarbeitet und nie hochgeladen. Es gibt keinen Server, der sie empfängt.
  • Keine Konten, also keine Nutzer zu verwalten und keine Passwörter, die abhandenkommen können.
  • Eine strenge Content Security Policy verhindert, dass die Seite Daten an andere Adressen sendet.
  • Open Source (AGPL-3.0): eure IT kann den Code auf GitHub lesen.
  • Funktioniert nach dem ersten Besuch auch offline.

In einer Minute eingeführt

Schickt dem Team den Link oder installiert LunaVerta als App aus Chrome oder Edge (das Installationssymbol in der Adressleiste). Nichts zentral zu installieren, keine Lizenzschlüssel, keine Updates zu verteilen. Funktioniert in Chrome, Edge, Safari und Firefox, auf Computer und Handy.

Eine eigene Version gewünscht?

Midt-Tech, das Unternehmen hinter LunaVerta, kann es in eurem eigenen Netzwerk betreiben, euer Logo einbauen oder die PDF-Abläufe entwickeln, die euer Unternehmen braucht.

Fragen zu LunaVerta

Ist es für Unternehmen wirklich kostenlos?

Ja. LunaVerta im Unternehmen zu nutzen ist kostenlos. Der Code steht unter AGPL-3.0, die nur verlangt, dass ihr Änderungen teilt, wenn ihr eine geänderte Version als öffentliche Website betreibt.

Können wir es selbst hosten?

Ja. LunaVerta ist ein Ordner mit statischen Dateien, jeder Webserver oder jedes Intranet kann ihn ausliefern. Code und Anleitung liegen auf GitHub.

Wer steht hinter LunaVerta?
