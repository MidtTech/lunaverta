Le travail PDF du quotidien pour toute l'équipe, sans licences ni envoi

Beaucoup d'entreprises paient des logiciels PDF que la plupart des gens utilisent surtout pour signer, fusionner et corriger un peu de texte. LunaVerta le fait gratuitement dans le navigateur, sur l'ordinateur de chacun, sans qu'aucune donnée client ne soit envoyée.

Essayer LunaVerta maintenant

Combien coûtent vos licences PDF ?

2 880 € par an → LunaVerta: 0 €

Exemple : Adobe Acrobat Pro pour les équipes coûte 180 DKK (environ 24 €) par utilisateur et par mois, hors TVA, avec un engagement annuel (prix catalogue danois d'Adobe, novembre 2026). Indiquez votre propre prix.

Ce que fait LunaVerta

  • Modifier le texte d'un PDF, ajouter du texte, remplir et créer des formulaires
  • Signer des contrats avec une signature dessinée ou importée
  • Fusionner, diviser, réordonner, faire pivoter, recadrer et compresser des PDF
  • Supprimer pour de bon numéros de sécurité sociale, prix et autres données personnelles
  • OCR en sept langues, comparaison de deux versions, protection par mot de passe
  • Word, Excel et PowerPoint en PDF ; PDF en Word, Excel et images

Ce qu'il ne remplace pas

  • Les signatures électroniques qualifiées avec certificat
  • Le PDF/A pour l'archivage à long terme
  • Les PDF prêts pour l'impression professionnelle (profils couleur, fonds perdus)

Si vous en avez besoin, gardez une licence pour les quelques personnes concernées. Tous les autres peuvent utiliser LunaVerta.

Bon pour le RGPD et la sécurité

  • Les fichiers sont traités dans le navigateur et ne sont jamais envoyés. Aucun serveur ne les reçoit.
  • Pas de comptes : aucun utilisateur à gérer, aucun mot de passe susceptible de fuiter.
  • Une Content Security Policy stricte empêche la page d'envoyer des données vers d'autres adresses.
  • Open source (AGPL-3.0) : votre service informatique peut lire le code sur GitHub.
  • Fonctionne hors ligne après la première visite.

Le déployer prend une minute

Envoyez le lien à l'équipe, ou installez LunaVerta comme application depuis Chrome ou Edge (l'icône d'installation dans la barre d'adresse). Rien à installer de façon centralisée, pas de clés de licence ni de mises à jour à déployer. Fonctionne dans Chrome, Edge, Safari et Firefox, sur ordinateur et téléphone.

Questions sur LunaVerta

Est-ce vraiment gratuit pour les entreprises ?

Oui. Utiliser LunaVerta dans votre entreprise est gratuit. Le code est sous AGPL-3.0, qui demande seulement de partager vos modifications si vous publiez une version modifiée comme site web.

Pouvons-nous l'héberger nous-mêmes ?

Oui. LunaVerta est un dossier de fichiers statiques : n'importe quel serveur web ou intranet peut l'héberger. Le code et les instructions sont sur GitHub.

Qui est derrière LunaVerta ?

Midt-Tech, un éditeur de logiciels à Aarhus, au Danemark (CVR 34256276).
