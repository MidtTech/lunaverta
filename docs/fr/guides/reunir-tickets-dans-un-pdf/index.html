Réunir des tickets dans un PDF

Les déclarations de sinistre, les notes de frais et les impôts demandent souvent les justificatifs en un seul fichier. Voici comment passer d'une pile de papiers à un PDF propre, avec seulement votre téléphone.

Étape par étape

  1. Ouvrez Scanner en PDF sur votre téléphone et photographiez le premier ticket.
  2. Les bords sont détectés et le ticket est redressé comme un vrai scan. Cliquez sur Ajouter une page et photographiez le suivant. Recommencez pour tous.
  3. Cochez Rendre le texte recherchable (OCR) pour pouvoir rechercher des montants plus tard.
  4. Cliquez sur Créer le PDF, puis sur Enregistrer. Tous les tickets forment maintenant un seul fichier.

Certains justificatifs sont déjà des PDF ?

Enregistrez votre scan, puis réunissez-le avec les autres PDF dans Fusionner PDF.

Trop lourd pour un e-mail ?

Beaucoup de messageries s'arrêtent à 20–25 Mo. Compresser PDF allège le fichier sans rendre les tickets difficiles à lire.
