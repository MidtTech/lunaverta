Everyday PDF work for the whole team, without licences or uploads

Many teams pay for PDF software that people mostly use to sign, merge and fix a bit of text. LunaVerta does that for free in the browser, on each person's own computer, so no client data is ever uploaded.

Try LunaVerta now

What do your PDF licences cost?

2,880 € per year → LunaVerta: 0 €

Example: Adobe Acrobat Pro for teams costs 180 DKK (about €24) per user per month, excl. VAT, on an annual plan (Adobe's Danish list price, November 2026). Type your own price.

What LunaVerta covers

  • Edit existing text in a PDF, add text, fill in and create forms
  • Sign contracts with a drawn or uploaded signature
  • Merge, split, reorder, rotate, crop and compress PDFs
  • Remove ID numbers, prices and other personal data for good
  • OCR in seven languages, compare two versions, password protection
  • Word, Excel and PowerPoint to PDF; PDF to Word, Excel and images

What it doesn't replace

  • Qualified electronic signatures with a certificate (such as MitID signing)
  • PDF/A for long-term archiving
  • Print-ready PDF for professional printing (colour profiles, bleed)

If you need those, keep a licence for the few people who do. Everyone else can use LunaVerta.

Good for GDPR and security

  • Files are processed in the browser and never uploaded. There is no server that receives them.
  • No accounts, so there are no users to manage and no passwords to leak.
  • A strict Content Security Policy stops the page from sending data to any other host.
  • Open source (AGPL-3.0): your IT team can read the code on GitHub.
  • Works offline after the first visit.

Rolling it out takes a minute

Send your team the link, or install LunaVerta as an app from Chrome or Edge (the install icon in the address bar). There is nothing to install centrally, no licence keys and no updates to push. It works in Chrome, Edge, Safari and Firefox, on computers and phones.

Questions about LunaVerta

Is it really free for companies?

Yes. Using LunaVerta in your company is free. The code is AGPL-3.0, which only asks that if you run a modified version as a public website, you share your changes.

Can we host it ourselves?

Yes. LunaVerta is a folder of static files, so any web server or intranet can host it. The source and instructions are on GitHub.

Who is behind LunaVerta?
