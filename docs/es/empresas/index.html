Trabajo diario con PDF para todo el equipo, sin licencias ni subidas

Muchas empresas pagan por programas de PDF que casi todo el mundo usa solo para firmar, unir y corregir un poco de texto. LunaVerta lo hace gratis en el navegador, en el propio ordenador de cada persona, así que ningún dato de clientes se sube.

Prueba LunaVerta ahora

¿Cuánto cuestan vuestras licencias de PDF?

2880 € al año → LunaVerta: 0 €

Ejemplo: Adobe Acrobat Pro para equipos cuesta 180 DKK (unos 24 €) por usuario al mes, sin IVA, con contrato anual (precio de lista de Adobe en Dinamarca, noviembre de 2026). Escribe vuestro propio precio.

Lo que hace LunaVerta

  • Editar el texto de un PDF, añadir texto, rellenar y crear formularios
  • Firmar contratos con una firma dibujada o subida
  • Unir, dividir, reordenar, girar, recortar y comprimir PDF
  • Eliminar números de identificación, precios y otros datos personales para siempre
  • OCR en siete idiomas, comparar dos versiones, protección con contraseña
  • Word, Excel y PowerPoint a PDF; PDF a Word, Excel e imágenes

Lo que no sustituye

  • Firmas electrónicas cualificadas con certificado
  • PDF/A para archivo a largo plazo
  • PDF listo para imprenta profesional (perfiles de color, sangrado)

Si lo necesitáis, mantened una licencia para las pocas personas que lo usan. Todos los demás pueden usar LunaVerta.

Bueno para el RGPD y la seguridad

  • Los archivos se procesan en el navegador y nunca se suben. No hay ningún servidor que los reciba.
  • Sin cuentas: no hay usuarios que gestionar ni contraseñas que se puedan filtrar.
  • Una Content Security Policy estricta impide que la página envíe datos a otras direcciones.
  • Código abierto (AGPL-3.0): vuestro equipo de TI puede leer el código en GitHub.
  • Funciona sin conexión tras la primera visita.

Ponerlo en marcha lleva un minuto

Enviad el enlace al equipo, o instalad LunaVerta como app desde Chrome o Edge (el icono de instalar en la barra de direcciones). Nada que instalar de forma centralizada, sin claves de licencia ni actualizaciones que distribuir. Funciona en Chrome, Edge, Safari y Firefox, en ordenador y móvil.

Preguntas sobre LunaVerta

¿De verdad es gratis para empresas?

Sí. Usar LunaVerta en vuestra empresa es gratis. El código es AGPL-3.0, que solo pide que compartáis vuestros cambios si publicáis una versión modificada como sitio web.

¿Podemos alojarlo nosotros?

Sí. LunaVerta es una carpeta de archivos estáticos, así que cualquier servidor web o intranet puede alojarla. El código y las instrucciones están en GitHub.

¿Quién está detrás de LunaVerta?

Midt-Tech, una empresa de software de Aarhus, Dinamarca (CVR 34256276).
