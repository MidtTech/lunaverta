# Security

LunaVerta processes files in the browser and has no server that receives them, so the most serious kind of bug is one that could make a file, or anything about it, leave the device. Others include redaction that leaves text recoverable, password protection that is weaker than stated, or a way to run untrusted code from an opened file.

Please report these privately by e-mail to **lee@midttech.com** rather than in a public issue. Include what you found, how to reproduce it, and which browser you used. You'll get a reply within a few working days, and credit in the release notes if you'd like.
